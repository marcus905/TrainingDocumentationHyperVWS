# Student Course Modules


## Concepts to keep in mind

The root Day 0–5 documents remain the complete technical source. The Student tree organizes that content into teaching units with explicit transitions, observations, validation checkpoints, and end states.

## Introduction

The student module tree is the live-delivery version of the course. Each file is intentionally small enough to open at the point where the instructor finishes explaining a concept and the class begins applying it.

This folder contains the student-facing, bite-sized delivery version of the Windows Server 2025 and Hyper-V course.

The full day files in the course root remain the canonical technical reference. These modules are optimized for live delivery, guided labs, revision and future slide-deck mapping.

## How to use these files

Each day has a day README, numbered modules, practical steps, validation checkpoints and a defined expected end state.

Troubleshooting modules use this flow:

~~~text
Break
  |
Observe symptom
  |
Investigate
  |
State root cause
  |
Correct
  |
Validate
  |
Reset
~~~

Instructor-only solutions are intentionally excluded.

## Slide-deck mapping

The module numbering is intended to map directly to future teaching decks. Example: `Day 3 / Module 04` maps to `Student/Day-3/04-Replica-Authentication.md` and to the corresponding Day 3 slide section.


## What you will do

Use each Day README as the navigation page and open only the current module during class. Return to the canonical day guide when deeper explanation or full command detail is required.


## What you should observe

The numbered module sequence also creates a stable reference for slide sections, instructor cues, and later student revision.


## Validation checkpoint

Students should always know three things from the current file: why the task matters, what they are expected to do, and what must be true before moving on.


## Expected end state

The student material functions as a guided learning path rather than a shortened copy of the canonical course notes.
